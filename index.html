SITCON 學生計算機年會

由學生發起的資訊社群與年會。

SITCON（學生計算機年會）由學生自發籌辦，提供技術分享與交流的舞台。我們透過年會、夏令營與黑客松，推廣資訊教育與開源精神，讓學生找到一起學習、實作的夥伴。

認識我們 從學生出發，連結更大的資訊社群

Since 2012 · 由學生發起

這個舞台，
有我們一起。

從 2012 年開始，SITCON 以學生為本，持續投入資訊教育與開源精神推廣。每一場交流背後，都是願意分享所學、一起做事的人。

從第一次參與，到走上講台、加入志工行列，學生的熱情在這裡匯聚，也讓知識與經驗持續傳承。

活動足跡

從年會、夏令營，到 Hour of Code 與黑客松，回顧 SITCON 歷年舉辦的活動，看見學習、交流與實作的不同樣貌。

01 Hour of Code

讓好奇，成為第一步。

第一次接觸程式，也能發現自己做得到。Hour of Code 透過容易親近的活動，降低資訊學習的門檻，陪伴孩子與學生探索程式的樂趣。

從資訊啟蒙開始，讓更多人有機會走進資訊世界。

認識 Hour of Code

02 SITCON Camp

把好奇，變成實作的能力。

五天四夜，和一群對資訊充滿好奇的夥伴一起學習。透過課程、動手實作與社群交流，學生能探索自己的興趣，也找到一起前進的同伴。

在共同學習中，感受分享與開源協作的精神。

認識 SITCON Camp

03 SITCON 年會

讓學生的聲音，被聽見。

學生不只是台下的聽眾，也能成為台上的分享者。年會匯聚各地資訊學子，讓技術實作、探索心得與不同觀點在這裡交流。

透過分享與經驗傳承，讓跨世代、跨領域的夥伴相遇。

認識 SITCON 年會

04 SITCON Hackathon

一起，把想法做出來。

從天馬行空的構想，到能夠展示的成果。黑客松讓參與者在緊湊的團隊協作中，一起發想、規劃並動手開發，練習解決問題。

讓創意透過實作成形，也讓學生團隊的能力被看見。
